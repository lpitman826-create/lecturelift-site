# LectureLift

A free gym and running planner for students. You enter your lectures and it fits training sessions around them. Built in Cardiff.

Live site: https://lecturelift.co.uk

## What is in this repo

A small static website, hosted on GitHub Pages. There is no build step.

- `index.html` is the whole site: every page, the styles and the scripts in one file.
- `sw.js` and `manifest.webmanifest` let people install it as an app and open it offline.
- `404.html`, `sitemap.xml`, `robots.txt`, `CNAME` and the icon and share images are the usual site files.

## Run it on your own computer

```
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser.
